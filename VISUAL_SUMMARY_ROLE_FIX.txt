# Role Assignment Issue - Visual Summary

## The Problem (Before Fix)

```
User clicks "Save" to assign role to user
        ↓
UserRoleAssignment.tsx calls rolePermissionService.assignRoleToUsers()
        ↓
Calls RPC function: assign_user_role(_user_ids, _role_id)
        ↓
Function tries to INSERT into user_roles table
        ↓
❌ ERROR: null value in column "role_id" violates not-null constraint
        ↓
⚠️  Role assignment FAILS
```

## Root Cause: Missing Migrations

```
Migrations Applied:  0000 → 0001 → ... → 0016 ✅
                     
Migrations Pending:  0017 → 0018 → ... → 0052 ❌
                     (37 MISSING MIGRATIONS!)
                     
Critical fixes in pending migrations:
├── 0049: Enforce role_id, remove legacy role field
├── 0050: Remove slug from roles table
├── 0051: Add NOT NULL constraint on role_id
└── 0052: Fix assign_user_role RPC function
```

## Why Were Migrations Pending?

```
Git Merge Conflict in:
  drizzle/migrations/meta/_journal.json
  
This file tracks which migrations have been applied.
The conflict made it think only 0000-0016 were applied,
when in reality all 52 migrations existed but were unapplied.
```
